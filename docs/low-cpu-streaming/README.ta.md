# குறைந்த செயலி பயன்பாடுடன் நேரலைக்கு AmF X1

இந்த வழிகாட்டி, TikTok LIVE Studio அல்லது OBS Studio போன்ற ஒரு ஸ்ட்ரீமிங் நிரலுடன், குறைந்த செயலி வளங்களைப் பயன்படுத்தி AmF X1-ஐ எப்படி இயக்குவது என்பதைக் காட்டுகிறது. இது விண்டோஸில் உள்ள AmF X1 1.24.0.5-க்குப் பொருந்தும்.

## பிராசசர் பயன்பாட்டை குறைவாக வைத்திருப்பது எது
- இன்புட் இல்லாத சேனல்கள் தவிர்க்கப்படுகின்றன. மௌனத்தை மட்டுமே கொண்டு, எந்த ஆடியோ விளைவுகளும் சேர்க்கப்படாத ஒரு சேனலுக்கு செயலாக்க நேரம் செலவாகாது.
- இடைமுகம் தானாகவே மெதுவாகும். நீங்கள் அதில் வேலை செய்யும்போது அது வினாடிக்கு 30 முறை மீண்டும் வரையறுக்கிறது, மற்றொரு நிரல் முன்னணியில் இருக்கும்போது வினாடிக்கு 4 முறையும், அது சிறியதாக்கப்பட்டிருக்கும்போது வினாடிக்கு ஒரு முறையும் வரையறுக்கிறது. ஒலி ஒருபோதும் மெதுவாக்கப்படுவதில்லை.
- கன்சோல் முன்னால் இருக்கும்போது, ஈகோ பயன்முறை மறுவரைவு விகிதத்தை பாதியாகக் குறைக்கிறது.
- ஆடியோ த்ரெட் செயலியின் வேகமான கோர்களில் இயங்குகிறது, மேலும் மற்றொரு நிரல் முன்னணியில் இருக்கும்போது இந்த இடைமுகம் பின்னணிப் பணியாகக் குறிக்கப்படுகிறது.
- ஒரு பெரிய பஃபர் என்பது குறைவான, பெரிய வேலைத் தொகுதிகளைக் குறிக்கிறது. பஃபர் அளவுகள் 32 முதல் 8192 மாதிரிகள் வரை செல்கின்றன.

## எங்கள் சோதனை இயந்திரத்தில் அளவிடப்பட்டது

கன்சோல் அதன் சுய-சோதனையில் தன்னை அளவிடுகிறது. எங்கள் சோதனை இயந்திரத்தில் (லினக்ஸ், கிராபிக்ஸ் கார்டு இல்லாமல் வரைதல், ஒரு செயலி கோர் கணக்கிடப்பட்டது) முழு நிரலும் முன்னணியில் இருக்கும்போது ஒரு கோரின் சுமார் 7 சதவீதத்தையும், மற்றொரு நிரலுக்குப் பின்னால் இருக்கும்போது சுமார் 5 சதவீதத்தையும், சுருக்கப்பட்ட நிலையில் இருக்கும்போது சுமார் 4 சதவீதத்தையும் பயன்படுத்தியது.

இந்த எண்கள் அந்த ஒரு இயந்திரத்திலிருந்து எடுக்கப்பட்டவை. உங்கள் கணினி வேறுபட்ட எண்களைக் கொடுக்கும். நாங்கள் இதை மற்ற தயாரிப்புகளுடன் ஒப்பிடவில்லை. TikTok LIVE Studio இயங்கும்போது விண்டோஸில் நாங்கள் இன்னும் இதை அளவிடவில்லை.

## ஸ்ட்ரீமிற்குத் தயார் செய்தல்
- TOOLS மெனுவைத் திறந்து LIVE MODE-ஐத் தேர்ந்தெடுக்கவும். மைக்ரோஃபோன் சேனலுக்கு ஒரு குரல் சங்கிலி கிடைக்கிறது: இரைச்சல் குறைப்பு, தானியங்கி மைக்ரோஃபோன் சமன்படுத்தி, லெவல் ரைடர் மற்றும் உச்சம் நீக்கி.
- ஸ்ட்ரீம் கிளிப் ஆகாமல் இருப்பதற்காக, மாஸ்டர் முழு அளவை விட 3 dB குறைவாக வைக்கப்பட்டுள்ளது.
- கண்காணிப்பு இயக்கப்பட்டிருக்கிறது. ஒலி அட்டை நின்றுவிட்டால், கன்சோல் தானாகவே ஒலியை மீண்டும் தொடங்கும்.
- இந்தச் சாளரம் நிலைகள் மற்றும் ஒரு மியூட் பொத்தானுடன் கூடிய லைவ் திரையை மட்டுமே காட்டுகிறது. இதை விட்டு வெளியேற கன்சோல் பின்கோடு தேவைப்படுவதால், விருந்தினர் கலவையை மாற்ற முடியாது.
- LIVE MODE-ஐத் தனியாகத் தொடங்க, TOOLS மெனுவில் AUTO LIVE-ஐ இயக்கவும். ஒரு ஸ்ட்ரீமிங் நிரல் திறக்கும்போது, LIVE MODE தொடங்கும்.
- ஸ்ட்ரீமிங் நிரலில், AmF X1-இன் ஒலி வெளியீட்டை ஆடியோ மூலமாகத் தேர்ந்தெடுக்கவும்.

## குறைந்த செயலாக்க சக்தியைப் பயன்படுத்துவது எப்படி
- ஸ்ட்ரீம் செய்யும்போது கன்சோலைச் சிறிதாக்குங்கள். அது பின்னர் ஒரு வினாடிக்கு ஒருமுறை மீண்டும் வரையப்படும்.
- 512 அல்லது 1024 மாதிரிகள் கொண்ட ஒரு பஃப்ஃபரைப் பயன்படுத்தவும். கன்சோல் வழியாக உங்களைக் கேட்கும்போது மட்டும் ஒரு சிறிய பஃப்ஃபரைப் பயன்படுத்தவும்.
- விளைவுகளைத் தேவைப்படும் சேனல்களில் மட்டுமே வைத்திருங்கள்.
- குறைக்க முன், பகுப்பாய்வி போன்ற பெரிய நகரும் காட்சிகளைக் கொண்ட பக்கங்களை மூடவும்.

## எல்லைகள்
- ஒரு பெரிய பஃபர் தாமதத்தைச் சேர்க்கிறது. 8192 சாம்பிள்கள் மற்றும் 48 kHz-இல், ஒரு பிளாக் சுமார் 171 மில்லிவினாடிகள் நீடிக்கும்.
- பூட்டத்தை நம்புவதற்கு முன்பு, ACCESS பக்கத்தில் உங்கள் சொந்த PIN-ஐ அமைக்கவும். தொழிற்சாலை PIN என்பது நிரலின் ஒவ்வொரு பிரதியிலும் ஒரே மாதிரியாகவே இருக்கும், எனவே அது எதையும் பாதுகாக்காது.
- தானியங்கி மைக்ரோஃபோன் சமன்படுத்தி குரலை அளந்து, அதன் தொனியைச் சரிசெய்கிறது. இது சிக்னல் செயலாக்கம், இயந்திரக் கற்றல் அல்ல.
