# 프로세서 사용량을 최소화하며 라이브 스트리밍을 할 수 있는 AmF X1

이 가이드에서는 TikTok LIVE Studio나 OBS Studio와 같은 스트리밍 프로그램을 실행하는 동안 AmF X1을 프로세서 부하를 최소화하면서 함께 실행하는 방법을 설명합니다. 이 내용은 Windows용 AmF X1 1.24.0.5 버전에 적용됩니다.

## 프로세서 사용량을 낮게 유지하는 요인은 무엇인가요?
- 입력이 없는 채널은 건너뜁니다. 무음만 전달하고 오디오 효과가 삽입되지 않은 채널은 처리 시간이 소요되지 않습니다.
- 인터페이스가 저절로 느려집니다. 인터페이스에서 작업할 때는 초당 30회, 다른 프로그램이 앞쪽에 있을 때는 초당 4회, 최소화되었을 때는 초당 1회 화면을 다시 그리게 됩니다. 소리는 절대 느려지지 않습니다.
- 콘솔이 전면에 표시되어 있는 동안 ECO 모드는 화면 갱신 빈도를 절반으로 줄입니다.
- 오디오 스레드는 프로세서의 고속 코어에서 실행되며, 다른 프로그램이 전면에 있을 때는 이 인터페이스가 백그라운드 작업으로 표시됩니다.
- 버퍼가 클수록 작업 블록의 수는 줄어들고 크기는 커집니다. 버퍼 크기는 32개에서 8192개 샘플까지 다양합니다.

## 당사의 테스트 장비에서 측정된 결과

이 콘솔은 자체 테스트를 통해 성능을 측정합니다. 테스트 환경(리눅스, 그래픽 카드 없이 실행, 프로세서 코어 1개만 집계)에서 전체 프로그램은 전면에 표시되었을 때 한 코어의 약 7%, 다른 프로그램 뒤에서 실행되었을 때 약 5%, 최소화되었을 때 약 4%의 리소스를 사용했습니다.

이 수치는 해당 기기 한 대에서 나온 것입니다. 사용하시는 컴퓨터에서는 다른 수치가 나올 수 있습니다. 다른 제품과의 비교는 진행하지 않았습니다. TikTok LIVE Studio가 실행 중인 상태에서 Windows 환경에서 측정해 보지는 않았습니다.

## 스트리밍 준비하기
- ‘도구(TOOLS)’ 메뉴를 열고 ‘라이브 모드(LIVE MODE)’를 선택합니다. 마이크 채널에 노이즈 감소, 자동 마이크 이퀄라이저, 레벨 라이더, 피크 제거기 등의 보정 체인이 적용됩니다.
- 스트림에 클리핑 현상이 발생하지 않도록 마스터 레벨을 풀 스케일보다 3dB 낮게 유지합니다.
- 워치독이 켜져 있습니다. 사운드 카드가 멈추면 콘솔이 자동으로 사운드를 다시 시작합니다.
- 이 창에는 레벨 표시와 음소거 버튼이 있는 LIVE 화면만 표시됩니다. 이 창을 닫으려면 콘솔 PIN이 필요하므로, 게스트는 믹스 설정을 변경할 수 없습니다.
- 라이브 모드를 단독으로 실행하려면 ‘도구’ 메뉴에서 ‘자동 라이브’를 켜십시오. 스트리밍 프로그램이 실행되면 라이브 모드가 시작됩니다.
- 스트리밍 프로그램에서 AmF X1의 사운드 출력을 오디오 소스로 선택하십시오.

## 처리 능력을 최소화하는 방법
- 스트리밍 중에는 콘솔을 최소화하세요. 그러면 1초에 한 번씩 화면이 새로 그려집니다.
- 512 또는 1024 샘플 크기의 버퍼를 사용하세요. 콘솔을 통해 자신의 연주를 들을 때만 작은 버퍼를 사용하세요.
- 효과가 필요한 채널에만 적용하십시오.
- 창을 최소화하기 전에 분석기 등 큰 움직이는 화면이 표시된 창을 닫으십시오.

## 한계
- 버퍼 용량이 크면 지연 시간이 늘어납니다. 8192 샘플, 48 kHz 조건에서 한 블록의 지속 시간은 약 171 밀리초입니다.
- 잠금 기능을 사용하기 전에 ‘ACCESS’ 페이지에서 직접 PIN을 설정하십시오. 공장 출하 시 설정된 PIN은 모든 프로그램 사본에서 동일하므로, 보안 기능을 제공하지 않습니다.
- 자동 마이크 이퀄라이저는 음성을 측정하여 음색을 보정합니다. 이는 기계 학습이 아닌 신호 처리입니다.
