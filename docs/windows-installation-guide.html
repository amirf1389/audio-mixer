AmF X1 — Windows Installation Guide

AMFB Audio · Version 1.26.0.0 · Updated 2026-11-27
Installer behaviour, command-line parameters and return codes for setup.exe and the MSI package

1. Packages

setup.exe (EXE)AmF-X1-1.26.0.0-setup.exe — full offline installer (NSIS). Installs the console, network service, Diagnostics app, 64-bit and 32-bit ASIO drivers, and an optional Windows Firewall rule for the phone remote.
MSIAmF-X1-1.26.0.0-x64.msi — per-machine Windows Installer package. Same program files; the ASIO drivers are registered from SETTINGS (as administrator) and no firewall rule is added.
Architecturex64 (Windows 10 version 1809 or later, Windows 11)
Install folderC:\Program Files\AmF X1
User data%APPDATA%\AMFB Audio\AmF X1 (settings, scenes, licence) and %LOCALAPPDATA%\AMFB Audio\AmF X1 (cache)

2. Command-line parameters

setup.exe

Silent installAmF-X1-1.26.0.0-setup.exe /S
Silent install, other folderAmF-X1-1.26.0.0-setup.exe /S /D=D:\Apps\AmF X1 (/D= last, no quotes)
Update and restart the app/S /RESTART (used by the built-in updater)
Silent uninstall"C:\Program Files\AmF X1\Uninstall.exe" /S (keeps the licence key)

MSI

Silent installmsiexec /i AmF-X1-1.26.0.0-x64.msi /qn
Install with a logmsiexec /i AmF-X1-1.26.0.0-x64.msi /qn /l*v install.log
Silent uninstallmsiexec /x AmF-X1-1.26.0.0-x64.msi /qn
UpgradesA newer MSI replaces an older version automatically; installing an older version over a newer one is blocked.

3. Return codes — setup.exe

CodeMeaningWhat to do
0SuccessAmF X1 is installed. Nothing to do.
1Cancelled by the userSetup was closed before it finished. Run setup.exe again and let it complete.
2Install failed (miscellaneous)Run setup.exe again as administrator (right-click, Run as administrator). If it fails again, re-download the installer from this site and check whether your antivirus quarantined any AmF X1 file.
112Not enough disk spaceFree space on the system drive (C:) and run setup again.
1618Another AmF X1 setup is already runningClose the other AmF X1 setup window (or wait for it to finish), then run setup again.
3010Installed, restart needed to finishRestart Windows to finish the installation (the audio driver is loaded after the restart).

4. Return codes — MSI

CodeMeaningWhat to do
0SuccessAmF X1 is installed. Nothing to do.
1602Cancelled by the userThe installation was cancelled. Run it again and let it complete.
1603Fatal error during installationRun the MSI again from an administrator command prompt with a log (see below). Re-download the MSI if the file may be damaged and check your antivirus quarantine.
1618Another installation is in progressWindows allows one installer at a time. Wait for the other installation (often Windows Update) to finish, or restart Windows, then try again.
1638Another version is already installedUninstall the existing AmF X1 from Settings, Apps, Installed apps, then install again.
3010Restart requiredAmF X1 is installed; restart Windows to finish.
112Disk fullFree space on the system drive (C:) and try again.

6. Logs and diagnostics

The MSI writes a full log when started with /l*v install.log. setup.exe does not write a log file; after installation, run AmF X1 Diagnostics from the Start menu to check the sound devices, drivers and network service.

7. What the installer changes

RegistryHKLM\Software\AMFB Audio\AmF X1 and the Apps & features entry (with quiet uninstall string and size).
ASIO drivers64-bit and 32-bit ASIO drivers registered (setup.exe only); removed on uninstall.
FirewallInbound TCP rule for the console and its network service, local subnet only, any port (setup.exe only); removed on uninstall.
RestartsNever restarts Windows itself. Returns 3010 if a file in use is replaced at the next restart.
Clean installA new install (not an update) clears earlier settings and caches but keeps the licence key.
Sign setup.exe and the MSI with the publisher's code-signing certificate before distribution. Unsigned packages fail Microsoft Store certification and trigger SmartScreen warnings.
