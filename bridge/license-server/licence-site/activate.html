Activate a computer

Type the machine code of the computer and your product key, licence key or edition token. The server checks the key and the free seats, then gives an activation for that one computer. AmF X1 then runs offline for the whole licence term.

Activation

Activated

Open in AmF X1

  1. OPEN IN AMF X1 saves amfx1-activation.amixkey to your Downloads folder.
  2. In AmF X1 open the LICENSE page with AUTO LICENCE on: it picks the file up within two seconds and activates.
  3. Or copy the activation into a text file named key.amixkey in Downloads: AmF X1 picks it up the same way.
