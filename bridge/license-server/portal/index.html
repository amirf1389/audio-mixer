AMF X1 Licence and updates

Activate with a product key

Type the 25-character product key you received. You get the full licence key for AmF X1.

  1. Easiest: press Save as a key file and leave the file in Downloads. With AUTO on (LICENCE page), AmF X1 finds it and activates by itself.
  2. Or: copy the key, open AmF X1 → LICENCE, paste it, press CHECK, then ACTIVATE.
  3. In AmF X1 you can also type the product key itself on LICENCE and press ACTIVATE PRODUCT KEY.

Check a licence key

Paste a full key (it starts with AMIX1) to see its edition, when it ends and whether it is still valid.
