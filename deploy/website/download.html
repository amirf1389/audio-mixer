Download

AmF X1 1.22.1.0 Beta. Beta builds are for testers: please report anything that does not work.

Windows

Windows 10 or 11. The setup includes everything it needs; no separate Node.js install.

Get the files on GitHub Releases

"Unknown publisher" warning: the installers are not yet signed with a commercial code-signing certificate, so Windows SmartScreen may warn you. Only download from this site or the GitHub page above. Updates inside the app are always checked against the AMFB Audio signing key before they install.

Linux and macOS

A .deb package and a .tar.gz for Linux, and a .tar.gz for macOS, on the same releases page.

After installing

  1. Start AmF X1 and choose your audio interface on the DAC & OS sources page.
  2. Basic works right away. For Pro, Studio or Master, request a key on the license page or message us on WhatsApp.
  3. Use CHECK KEY to see what a key unlocks before you activate it.
