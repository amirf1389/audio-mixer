Check a download

Compare the result with the SHA-256 in the table above. If they differ, do not run the file.

# Windows (PowerShell)
Get-FileHash ".\AmF X1-1.22.1.0-beta.exe" -Algorithm SHA256

# macOS
shasum -a 256 AudioMixer-1.22.1.0-macos.tar.gz

# Linux
sha256sum audio-mixer_1.22.1.0_all.deb

After installing

  1. Start AmF X1 and choose your audio interface on the DAC & OS sources page.
  2. Basic works right away. For Pro or Studio Master, use UPGRADE on the LICENSE page of the app, the editions page, or message us on WhatsApp.
  3. Use CHECK KEY to see what a key unlocks before you activate it.
  4. If a device has no sound, open DIAGNOSTICS on the DAC & OS sources page and use COPY REPORT to send us the log.

System requirements

  • Windows 10 or 11 (64-bit; a 32-bit MSI is available), macOS, or a 64-bit Linux.
  • Any audio interface: ASIO drivers are used when present, Windows audio (WASAPI), Core Audio or ALSA otherwise.
  • A current browser engine for the console (the Windows setup includes everything it needs).
