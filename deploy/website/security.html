Security

What AmF X1 does to protect your computer, your audio and your data.

Local only

The bridge stays on your PC

It listens on 127.0.0.1 and checks the host name and the calling page. Other websites cannot change settings, restart your PC or open your microphone.

Signed

Updates and licenses

Updates and license keys are checked with an ECDSA P-256 signature against the AMFB Audio key built into the app. A changed file is refused.

Encrypted

Key requests

Names, e-mail addresses and machine codes in key requests are encrypted to the vendor key (ECIES with AES-256-GCM) and can only be read with the vendor's PIN.

Hardened

Runtimes and website

Node.js 22 security releases, Electron security updates, and a website with HTTPS, HSTS and a strict content security policy.

Reporting a security problem

E-mail badriamirfakhri@gmail.com with the steps to reproduce it. Please give us time to fix it before telling others. There is no bug bounty.
