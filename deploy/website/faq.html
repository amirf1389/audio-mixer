Frequently asked questions

Which Windows versions does AmF X1 support?

Windows 10 and Windows 11, 64-bit, with a 32-bit MSI for older PCs. Linux and macOS builds are also available.

Do I need an ASIO driver?

No. AmF X1 uses your interface's own ASIO driver when it has one for the lowest latency, and Windows audio (WASAPI) otherwise. Onboard sound such as Realtek works through Windows audio.

Does it work with the Behringer UM2 and similar USB interfaces?

Yes, through its own ASIO driver (BEHRINGER USB AUDIO) or through Windows audio (USB Audio CODEC). The UM2 microphone is on input 1 only. If you get no signal, close other audio programs that may hold the ASIO driver, or read the device through Windows audio.

What does Beta mean?

Version 1.22.1.0 Beta is a test version with new features. It may still have problems; please report them so they can be fixed before the final release.

How do I activate a license?

Request a key on the license page or on WhatsApp, paste it on the LICENSE page of AmF X1, press CHECK KEY to see what it unlocks, then ACTIVATE.

Does AmF X1 send my audio or data anywhere?

No. Audio stays on your computer. The app only goes online to check for signed updates, and key requests are sent only when you choose to.

Why does Windows say "unknown publisher"?

The installers are not yet signed with a commercial code-signing certificate. Download only from this site or the official GitHub releases page.
