AMF X1 · RELEASE MANAGER

Edits releases/features.json, the feature feed the console shows under WHAT'S NEW (NEW badge in the header). Nothing here is sent anywhere: the page runs in your browser only. Save the file into the repository, then sign the manifest on the vendor machine with node scripts/make-update.js (the key never leaves that machine). Clients accept only a manifest signed with the vendor key.


Then: git add releases/features.json && node scripts/make-update.js && git commit -am "release feed" on the vendor machine.
